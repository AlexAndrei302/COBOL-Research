
# COBOL Research

Forschungsprojekt - UBB Informatik (Deutsch)

## Thema
Zusammenhang zwischen Änderungshäufigkeit und
statisch erkennbaren Qualitätsproblemen in
Open-Source-COBOL-Code.

## Forschungsfrage
Gibt es einen Zusammenhang zwischen der Anzahl
der Commits einer COBOL-Datei und der Anzahl
bzw. Dichte statisch erkennbarer Qualitätsprobleme?

## Datensatz
X-COBOL (Ali et al., 2023)

## Aktueller Stand
Woche 7 - Beginn der Implementierung.

## Geplante Schritte
- COBOL-Dateien lesen
- GO TO und ALTER erkennen
- Automatisierte Tests implementieren
- X-COBOL-Daten untersuchen
